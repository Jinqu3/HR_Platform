"📋 ТЗ: Сервис ИИ-скрининга резюме «HR-Sieve»

1. ФУНКЦИОНАЛ (MVP):
• Рекрутер создает вакансию (стек, опыт, требования).
• Bulk Upload: загрузка ZIP-архива с резюме (PDF/DOCX).
• Real-time прогресс-бар обработки архива для пользователя.
• Лидерборд кандидатов: ранжирование по ИИ-скорингу (0-100) + саммари.

2. СТЕК И ИНФРАСТРУКТУРА:
• Backend: FastAPI (асинхронный, Луковичная/Чистая архитектура).
• Tasks: Celery + RabbitMQ (цепочки задач: unzip -> parse -> AI score).
• DB & Cache: PostgreSQL (данные) + Redis (кэш, дедупликация, прогресс-бар).
• Мониторинг: Flower.

3. КАЧЕСТВО КОДА И МЕТРИКИ (CI/CD):
• Чистота: Линтинг и форматирование через Ruff (строгий пресет).
• Типизация: Статический анализ Mypy (в режиме --strict).
• Тесты: Pytest + Testcontainers (интеграционные тесты БД/Redis).
• Покрытие: Строго >= 90% общего Code Coverage (pytest-cov).

4. ВЗАИМОДЕЙСТВИЕ КОМПОНЕНТОВ:
• FastAPI принимает архив, пишет в БД статус PENDING, пушит задачу в RMQ и за <100мс возвращает 202 Accepted.
• Celery-воркеры параллельно парсят файлы и запрашивают ИИ, атомарно инкрементируя прогресс в Redis (INCR).
• FastAPI через эндпоинт выдает клиенту статус из Redis, не нагружая Postgres."
